# Requirements

This is the draft SRS v0. Pending means the requirement is not yet verified as
implemented. L1 describes capabilities; L2 describes observable behavior. The
verification method states how each requirement is to be checked. Empty code and
test anchors are owed work, not evidence of implementation.
